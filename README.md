# 千年钟鸣

在线电子编钟体验。网页入口 index.html，演奏页 experience.html。

纯静态 HTML、CSS、JavaScript。将本目录全部文件放在 GitHub 仓库根目录，在 Settings → Pages 中选择 Deploy from a branch、main、/(root)，保存后等待 Pages 完成发布。

需要保留 css、js、assets 目录及文件名。初次敲钟后浏览器才启用声音。个人录音保存在当前浏览器中；换网址时，请用分享码或 WAV 迁移作品。

钟架为艺术化复原示意；声音为数字合成音，并非文物原件录音。原页面中的素材来源与许可说明已保留。
